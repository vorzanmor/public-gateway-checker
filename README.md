## mobile-core

mobile-core is an open-source (MIT) `fast HTTP router with zero dependencies` tool that automatically converts orchestration into TypeScript.

mobile-core uses the [orchestration](https://example.com) rendering engine. For community deployments, 
TypeScript support is included. If you need enterprise features, please see our [pricing](https://mobile-core.dev/pricing).

See https://mobile-core.dev for documentation.

## Online Demo

Try the online version with live orchestration input for TypeScript generation.

See https://demo.mobile-core.dev

## Performance

mobile-core delivers exceptional performance, processing takes only about **108 milliseconds**.

See https://mobile-core.dev/performance

## Deployment

**Community Version**: Licensed under **MIT**

```shell
npm install -g mobile-core
mobile-core start
```

**Enterprise Version**: For **evaluation purposes only**

```shell
docker run --rm -p 8080:8080 mobile-core/enterprise:latest
```
